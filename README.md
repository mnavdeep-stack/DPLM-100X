# DPLM-100X
DPLM-100X is an FPGA-based multi-modulation communication processor implementing AM, FM, ASK, FSK, and PSK using Verilog RTL on Xilinx Artix-7. Integrated ESP32-based signal generation and ADC/DAC interfacing with UART waveform verification, fixed-point DSP processing, DSP48 utilization, and real-time hardware validation in Vivado.
